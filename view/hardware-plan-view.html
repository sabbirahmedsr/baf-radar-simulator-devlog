Station Configuration

Each station is configured with specific hardware and software roles. The architecture utilizes the Existing ATC Server as the core master node, while client stations synchronize in real-time to ensure a cohesive training environment.

Master Server [Existing ATC Server - Reutilized for Radar Simulation]

  • PC Specification: High-End Workstation with Dedicated GPU
  • Display Setup: 1x Monitor + Tripple Screens
  • Peripherals: Keyboard, Mouse, Master PTT Headset
  • Core Role: Manages simulation state, master ASR/PAR overview, & network sync

Instructor

  • PC: Mid-Range
  • Displays: 2x Monitor (ASR / PAR Scopes)
  • Peripherals: Keyboard, Mouse, PTT Headset
  • Master control over simulation scenarios
  • Injects malfunctions & weather updates
  • Instructor override & channel monitoring

Pilot (1 to 4)

  • PC: Mid-Range
  • Displays: 1x Monitor
  • Peripherals: Keyboard, Mouse, PTT Headset
  • Receives real-time simulation data
  • Executes manual heading, alt, speed inputs
  • PTT voice communication with controllers

Student / ATC

  • PC: Mid-Range
  • Displays: 2x Monitor (ASR / PAR Scopes)
  • Peripherals: Keyboard, Mouse, PTT Headset
  • Receives real-time simulation data
  • Active ASR/PAR approach & separation view
  • PTT voice for air traffic control

Hardware Resource & Procurement Summary

To optimize cost and maximize existing infrastructure, the Radar Simulator reuses core ATC hardware while proposing only the essential client workstations required for full multi-role operations.

Existing Hardware (To Be Re-utilized)

  • 1x Master Server PC: Existing ATC Server (High-End PC + Trio Screens) will act as the central simulation engine.
  • 2x Pilot Stations (Pilot 1 & Pilot 2): Existing Departure (DEP) and Arrival (ARR) consoles will be integrated directly.
  • Core LAN Infrastructure: Existing network switch and room wiring framework.

New Hardware (Proposed Procurement)

  • 1x Instructor Workstation: Mid-range PC with 2x Monitors (for Master ASR/PAR oversight) + PTT Headset.
  • 1x Student / ATC Workstation: Mid-range PC with 2x Monitors (for dedicated ASR & PAR scopes) + PTT Headset.
  • 2x Additional Pilot Workstations (Pilot 3 & Pilot 4): Mid-range PCs, each with 1x Monitor + PTT Headset.

Shared Peripherals & Custom Voice Hardware [System-Wide Requirement]

  • PTT Headsets (All Stations): Dedicated Push-to-Talk (PTT) headsets are required across ALL STATIONS (both existing and newly proposed), as current ATC terminals lack PTT-compatible headsets.
  • Custom Voice Control Hardware: Additional dedicated audio interfaces, PTT switches, or custom voice control hardware may be required depending on final system architecture discussions.

Network & Cable Management

A clean and organized setup is crucial for maintenance and reliability.

  • Network: All computers will be connected via a dedicated, high-speed Local Area Network (LAN) using the central network switch to ensure low latency.
  • Cabling: All power and network cables will be managed using under-desk cable trays and raceways to prevent clutter and tripping hazards.
  • Peripherals: Each station will be equipped with a monitor, keyboard, mouse, and headset, with cables neatly routed.
